## Current Portfolio Description

TriageCore is a local-first, evidence-bound research workbench for governing
AI-assisted decisions and consequential actions. The repository includes an
integrated governed run and evidence path, an optional bounded Qwen route, a
separate human-authorization and atomic-capability lane, and
implemented-but-disconnected mediated-execution foundations. Independent
evaluator execution, meta-harnesses, bounded agents, and a TriageDesk action
bridge remain external, conceptual, or future rather than one end-to-end safety
system. Resource-aware routing is one governed subsystem, not the whole identity.
Environmental and edge workflows remain adjacent application domains, not an
implemented field system.

## Safe Short Description

TriageCore is a local-first, evidence-bound research workbench for governing
AI-assisted decisions and consequential actions through explicit authority and
reviewable artifacts.

Do not describe TriageCore as:

- a production platform;
- a general agent runtime;
- a complete containment system;
- a safety-certification authority;
- an end-to-end authorization and execution system;
- a deployed independent evaluator; or
- an implemented environmental field system.
